# 1日のタスクスケジューラー

タスク名・優先順位・所要時間を入力すると、優先度の高いタスクから **9:00〜18:00** に自動で割り当てるWebアプリケーションです。

## 使い方

ビルドやサーバーは不要です。`index.html` をブラウザで開いてください。

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

ローカルサーバー経由で開く場合：

```bash
npx http-server -p 8080 .
# → http://localhost:8080
```

## 機能

- **追加**：タスク名／優先順位（1が最優先）／所要時間（分）を入力して登録
- **編集**：一覧の「編集」から内容を修正し「更新する」で反映
- **削除**：タスク単位の削除、および「すべて削除」
- **自動スケジューリング**：優先順位順に 9:00 から連続して割り当て、割り当て時間・空き時間を表形式で表示
- **表からの直接変更**：スケジュール表の中で優先順位・所要時間をその場で変更（変更すると即座に再スケジュール）
- **優先順位の重複時の比較選択**：既に使われている優先順位を入力すると、対象タスクと既存タスクを並べて「どちらを先に実行するか」を選べます
- **保存**：ブラウザの localStorage に保存され、再読み込みしても内容が残ります
- **テキスト出力**：スケジュールをプレーンテキストで表示し、ワンクリックでコピー／`.txt` ダウンロード

## スケジューリングの仕様

- 対象時間は 9:00〜18:00（540分）。
- 優先順位の数値が小さいタスクから順に、9:00 から間を空けずに割り当てます。
- 優先順位は常に 1〜n の連番になるよう自動で振り直されます（同じ順位のタスクは存在しません）。
- 残り時間に収まらないタスクは飛ばし、後続の短いタスクで空き時間を埋めます。収まらなかったタスクは表の下部に「割り当てできなかったタスク」としてまとめて表示され、そこでも優先順位・所要時間を変更できます。

## 優先順位の変更と重複時の比較

優先順位は、次の2か所から変更できます。

- 「タスクを追加」フォーム（追加時・編集時）
- スケジュール表の「優先順位」欄（数値を入力して Enter またはフォーカスを外す）

入力した優先順位を既に他のタスクが使っている場合は、比較ダイアログが開きます。

```text
優先順位 2 には既に「定例ミーティング」があります。どちらを先に実行しますか？

  ┌ 「緊急対応」を先にする      所要 30分  → 優先順位 2（先に実行）
  └ 「定例ミーティング」を先にする  所要 1時間 → 優先順位 2（先に実行）
```

選んだほうがその順位になり、もう一方は1つ繰り下がります。以降のタスクの順位も連番のまま自動で詰め直されます。キャンセルすると順位の変更は行われません。

所要時間はスケジュール表の「所要時間（分）」欄で直接変更できます（5分単位、5〜540分）。変更するとその場で全体が再スケジュールされます。

## テキスト出力

画面下部の「テキスト出力」に、そのまま貼り付けられる形式のスケジュールが常に最新の内容で表示されます。

- **コピー**：クリップボードにコピー（`file://` で開いた場合など、クリップボードAPIが使えない環境では自動的にテキストを選択状態にします）
- **.txt をダウンロード**：`schedule-YYYY-MM-DD.txt` として保存（Windows でも文字化けしないよう BOM 付き UTF-8）

出力例：

```text
2026/8/18（火） のスケジュール（09:00〜18:00）
============================================

09:00〜11:00  企画書の作成  [優先1・2時間]
11:00〜12:00  定例ミーティング  [優先2・1時間]
12:00〜12:45  メール返信  [優先3・45分]
12:45〜17:15  資料レビュー  [優先4・4時間30分]
17:15〜18:00  （空き時間）  [45分]

■ 割り当てできなかったタスク
- 日報作成  [優先5・1時間30分]

--------------------------------------------
タスク 5件 / 割り当て 4件・8時間15分 / 空き 45分 / 未割り当て 1件
```

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル（ライト／ダークモード対応、レスポンシブ） |
| `app.js` | タスクのCRUD、スケジューリング、テキスト出力、localStorage への保存 |
