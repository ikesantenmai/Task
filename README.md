# 1日のタスクスケジューラー

タスク名・優先順位・所要時間を入力すると、優先度の高いタスクから **7:00〜22:00** に自動で割り当てるWebアプリケーションです。

## 使い方

ビルドやサーバーは不要です。`index.html` をブラウザで開いてください。

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

ローカルサーバー経由で開く場合：

```bash
npx http-server -p 8080 .
# → http://localhost:8080
```

## 機能

- **追加**：タスク名／優先順位（1が最優先）／所要時間（分）に加え、**詳細・依頼先・期限**を入力して登録
- **依頼**：依頼先にメールアドレスを入れると「依頼メール」ボタンが出て、タスクの内容を差し込んだ下書きを開けます
- **編集**：一覧の「編集」から内容を修正し「更新する」で反映
- **削除**：タスク単位の削除、「週間表を残してクリア」（一覧と自動スケジュールだけを空にする）、「すべて削除」
- **自動スケジューリング**：優先順位順に 7:00 から連続して割り当て、割り当て時間・空き時間を表形式で表示
- **表からの直接変更**：自動スケジュール表の中で優先順位・所要時間をその場で変更（変更すると即座に再スケジュール）
- **週間スケジュール**：自動スケジュール表の行を下の週間表（月〜日）にドラッグ＆ドロップして、任意の日時に固定
- **週の切り替え**：「前週」「今週」「翌週」で表示する週を変え、今週以外にもタスク・予定を配置
- **予定の入力**：優先度を持たない予定（会議・昼休みなど）を週間表に直接追加・編集・削除
- **終日の予定**：週間表のいちばん上の「終日」枠に、1日あたり何件でも終日の予定を登録・移動
- **タッチ操作対応**：iPhone・iPad などタッチ端末でも指でドラッグして移動（画面端まで運ぶと自動スクロール）
- **優先順位の重複時の比較選択**：既に使われている優先順位を入力すると、対象タスクと既存タスクを並べて「どちらを先に実行するか」を選べます
- **保存**：タスク・予定・配置した時刻はブラウザの localStorage に保存され、再読み込みしても内容が残ります
- **日本語／英語の切り替え**：画面右上の「言語」で切り替え（既定は日本語、選択内容は保存されます）
- **月間カレンダー**：画面下部に月表示のカレンダーを表示し、日付をクリックするとその週を週間スケジュールに表示
- **日付と時刻を選んで追加**：自動スケジュール表の各行で日付と時刻（自動／30分刻み）を選び、「追加」で週間表へ配置
- **Excel出力**：日単位／週単位／すべて を切り替えて `.xlsx` ファイルを出力
- **Excel取り込み**：日単位はその日だけ、週単位はその週だけを上書きし、「すべて」は全期間を置き換え

## 表示言語（日本語／英語）

画面右上の「言語」プルダウンで、日本語版と英語版を切り替えられます。

- 既定は**日本語**です。切り替えた言語は localStorage に保存され、次に開いたときも保持されます。
- 画面の文言だけでなく、曜日名（月／Mon）、日付表記（`8/20（木）`／`8/20 (Thu)`）、所要時間（`1時間30分`／`1h 30m`）、メッセージや確認ダイアログも切り替わります。
- Excel の出力も表示言語に合わせた見出し（`種別`／`Type` など）になります。取り込みは**日本語版・英語版どちらのファイルにも対応**しているため、言語をまたいだやり取りもできます。
- 文言は `i18n.js` の辞書にまとまっています。言語を増やす場合は、この辞書に同じキーの組を追加します。

## スケジューリングの仕様

- 対象時間は 7:00〜22:00（900分）。
- 優先順位の数値が小さいタスクから順に、7:00 から間を空けずに割り当てます。
- 優先順位は常に 1〜n の連番になるよう自動で振り直されます（同じ順位のタスクは存在しません）。
- 残り時間に収まらないタスクは飛ばし、後続の短いタスクで空き時間を埋めます。収まらなかったタスクは表の下部に「割り当てできなかったタスク」としてまとめて表示され、そこでも優先順位・所要時間を変更できます。
- 自動スケジュールは1日分の提案です。曜日ごとの実際の予定は、下の週間スケジュールで組み立てます。

## タスクの詳細・依頼先・期限

タスクには次の項目を持たせられます（いずれも任意）。

| 項目 | 内容 |
| --- | --- |
| 詳細 | 作業内容やメモ（400文字まで）。一覧では2行まで表示し、全文はツールチップと編集フォームで確認できます |
| 依頼先 | 担当者の名前、またはメールアドレス（200文字まで）。**複数人**を書けます |
| 期限 | 日付。過ぎていれば赤い「期限切れ」、当日は「本日期限」として強調します |

- 依頼先と期限は、タスク一覧・自動スケジュール表・週間表のブロックにバッジとして表示されます。
- 依頼先に**メールアドレスが1つでも含まれていれば**、一覧に「依頼メール」ボタンが出ます。押すとタスク名・期限・所要時間・優先順位・詳細を差し込んだメールの下書き（`mailto:`）が開きます。
- 複数のメールアドレスを書くと、全員が宛先に入ります（ボタンは「依頼メール（3人）」のように人数付きになり、マウスを乗せると宛先の一覧が出ます）。区切りはカンマ `,`・セミコロン `;`・読点 `、`・空白のいずれでもよく、`山田さん yamada@example.com、佐藤 <sato@example.com>` のように名前が混じっていてもアドレスだけを取り出します（重複は1つにまとめます）。
- Excel には `期限` `依頼先` `詳細` の列が追加され、出力・取り込みの両方で往復します。

## タスク一覧のクリア

タスク一覧の見出しには2つのボタンがあります。

| ボタン | 動作 |
| --- | --- |
| 週間表を残してクリア | タスク一覧と自動スケジュールを空にします。週間表に配置済みのタスクは、**時間も見た目もそのまま**週間表に残ります（優先順位の表示も保持）。次の日の計画を立て直すときに使います |
| すべて削除 | タスクを配置ごとすべて削除します |

「週間表を残してクリア」で残った項目は、週間表の中で移動・編集・削除ができます（一覧には戻らないため、ボタンは「解除」ではなく「編集」「削除」になります）。Excel出力では引き続き `種別 = タスク` として優先順位付きで出力されます。

## 週間スケジュール（ドラッグ＆ドロップ）

画面下部の週間表は、縦が 7:00〜22:00 の30分刻み、横が表示中の週の月曜〜日曜です（今日の列は色が変わります）。ここには次の2種類を並べられます。

| 種類 | 追加方法 | 見た目 |
| --- | --- | --- |
| 優先度つきタスク | 自動スケジュール表の行の「⠿」をドラッグして落とす | 青いブロック |
| 優先度のない予定 | 週間表の上にあるフォームから追加 | 破線のブロック |

- **移動**：配置したタスクも予定も、ブロック左の「⠿」をドラッグして週内の別の日時へ移動できます。
- **日付と時刻を選んで追加**：ドラッグの代わりに、自動スケジュール表の右端で日付と時刻を選んで「追加」を押すこともできます（日付は表示中の週、時刻は30分刻み）。時刻を「自動」にすると、自動スケジュールと同じ時刻を優先し、そこが埋まっていればその日の最も早い空き時間に置きます。時刻を指定した場合、その時間が埋まっている・22:00 を超えるときは配置せず理由を表示します。配置済みのタスクは、その日時が初期値として選ばれます。自動スケジュールと同じ時刻に置き、そこが埋まっている場合はその日の最も早い空き時間に置きます。
- **タッチ操作**：iPhone・iPad などでも指でドラッグできます（HTML5 のドラッグ＆ドロップではなく Pointer Events で実装しているため）。ドラッグ中に画面の上下端へ運ぶとページが、左右端へ運ぶと週間表が自動でスクロールします。
- タスクのブロックは「解除」で配置を取り消せます（タスク自体は残ります）。すべて取り消す場合は「配置をすべて解除」を使います。
- 予定のブロックは「編集」で名前・日・開始時刻・所要時間を変更でき、「削除」で消せます。
- 同じ日の他のタスク・予定と重なる場合や 22:00 を超える場合は配置されず、表の下にその理由が表示されます。
- 所要時間を変更して配置が成立しなくなったタスクは、自動的に配置が解除されます（メッセージで通知）。予定はそのまま残ります。
- 空いているコマをクリック（タップ）すると、その日時が予定フォームに入ります。
- 配置内容は localStorage に保存され、配置済みのタスクには自動スケジュール表側に「配置済み 8/20（木） 14:00」バッジが付きます。
- 配置は日付（`YYYY-MM-DD`）で保存するため、週をまたいでも位置が変わりません。

### 週の切り替え

週間表の見出しにある「← 前週」「今週」「翌週 →」で、表示する週を何週でも前後に動かせます。

- 表示中の週の範囲は見出しの下に表示されます（例：`2026/8/24（月） 〜 2026/8/30（日）（翌週）`）。表示中の週の外に配置がある場合は「他の週に N件」と一緒に表示されます。
- 週を切り替えると、自動スケジュール表の「週間表へ追加」欄、予定フォームの「日」、Excelの日付選択も、その週の日付に切り替わります。
- 「今週」ボタンは今週を表示中は押せない状態になります。

### 終日の予定

週間表の時間帯の上には「終日」の行があり、時間を決めない予定（研修・出張・締切など）を置けます。

- 各日のセルの「＋」を押すと、その日で終日にチェックが入った状態で予定フォームが開きます。予定フォームの「終日」チェックからも登録できます（終日のときは開始時刻と所要時間は使いません）。
- **1日に何件でも**登録でき、セル内に縦に並びます。
- 予定名をクリックすると編集、「×」で削除できます。左の「⠿」をドラッグすると別の日の終日枠へ移動できます（タッチ操作にも対応）。
- 終日の予定は時間帯を占有しないため、同じ日の時間つきタスク・予定とは重なり判定を行いません。
- 終日の枠には終日の予定だけを置けます（時間つきの項目をドラッグすると、その旨を表示して何もしません）。
- Excel では `開始` 列が `終日`（英語版は `All day`）の行として出力・取り込みされ、月間カレンダーでは「終日 ○○」として先頭に表示されます。

### 予定（優先度なし）の入力

| 項目 | 内容 |
| --- | --- |
| 予定名 | 40文字まで |
| 日 | 表示中の週の月〜日 |
| 開始時刻 | 7:00〜21:30 の30分刻み |
| 所要時間 | 5〜900分 |

タスクは優先順位を持ち自動スケジュールの対象になりますが、予定は優先順位を持たず、週間表に固定される点だけが違います。

## 優先順位の変更と重複時の比較

優先順位は、次の2か所から変更できます。

- 「タスクを追加」フォーム（追加時・編集時）
- 自動スケジュール表の「優先順位」欄（数値を入力して Enter またはフォーカスを外す）

入力した優先順位を既に他のタスクが使っている場合は、比較ダイアログが開きます。

```text
優先順位 2 には既に「定例ミーティング」があります。どちらを先に実行しますか？

  ┌ 「緊急対応」を先にする      所要 30分  → 優先順位 2（先に実行）
  └ 「定例ミーティング」を先にする  所要 1時間 → 優先順位 2（先に実行）
```

選んだほうがその順位になり、もう一方は1つ繰り下がります。以降のタスクの順位も連番のまま自動で詰め直されます。キャンセルすると順位の変更は行われません。

所要時間は自動スケジュール表の「所要時間（分）」欄で直接変更できます（5分単位、5〜900分）。変更するとその場で全体が再スケジュールされます。

## 月間カレンダー

画面下部に、月〜日の並びで1か月を表示するカレンダーがあります。

- 「← 前月」「今月」「翌月 →」で月を移動します（6週間分の枠を常に表示）。
- 各日には、その日に配置したタスク・予定が開始時刻の早い順に表示されます（3件まで、超える分は「他 N件」）。タスクは青、優先度のない予定は破線で区別します。
- 今日の日付は枠線と「今日」バッジで強調され、土日は色を変えています。
- 日付をクリックすると、その日を含む週が上の週間スケジュールに表示され、画面がそこまでスクロールします。

## Excel出力・取り込み

画面下部の「Excel出力・取り込み」では、出力される内容がそのままプレビュー表として表示されます。

### 出力

| 範囲 | 内容 | ファイル名 |
| --- | --- | --- |
| 日単位 | 選んだ日に固定したタスク・予定＋未配置のタスク | `schedule-YYYY-MM-DD.xlsx` |
| 週単位 | 表示中の週に固定したタスク・予定＋未配置のタスク | `schedule-week-YYYY-MM-DD.xlsx` |
| すべて | 全期間（すべての週）のタスク・予定＋未配置のタスク | `schedule-all-YYYY-MM-DD.xlsx` |

シートの構成は次のとおりです（1行目がタイトル、2行目が範囲（`日単位`／`週単位`／`すべて`）、3行目が見出し、4行目以降がデータ）。

| 種別 | 曜日 | 日付 | 開始 | 終了 | 名称 | 優先順位 | 所要時間（分） | 期限 | 依頼先 | 詳細 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| タスク | 水 | 2026-08-19 | 11:00 | 12:00 | 定例ミーティング | 2 | 60 | 2026-08-20 | 佐藤さん | 議事録も作成 |
| 予定 | 水 | 2026-08-19 | 12:00 | 13:00 | 昼休み | | 60 | | | |
| タスク | | | | | メール返信 | 3 | 45 | | | |

- **種別**：`タスク`（優先順位あり）か `予定`（優先順位なし）
- **曜日・開始**：週間表に固定している場合のみ入る。空欄なら未配置のタスク
- **終了**：確認用（取り込み時は使いません）
- **期限・依頼先・詳細**：タスクの付加情報。予定の行では空欄になります

### 取り込み

「Excelを取り込む」から `.xlsx` を選ぶと、`種別` と `名称` の見出し行を探して読み込みます。ファイルの範囲（日単位／週単位／すべて）で動作が変わります。出力時にシートへ書き込む「範囲」の行で判定し、無い場合はタイトルや日付の散らばり（複数週にまたがれば「すべて」、1週内に収まれば「週単位」、1日だけなら「日単位」）から推測します。

| ファイル | 動作 |
| --- | --- |
| **日単位** | 取り込む日を選ぶダイアログが開き（表示中の週の中から選択）、**選んだ日だけ**をファイルの内容に上書きします。他の日はそのまま残ります |
| **週単位** | 確認のうえ、**ファイルの日付が属する週だけ**（日付が無ければ表示中の週）をファイルの内容に上書きします。他の週はそのまま残ります |
| **すべて** | 確認のうえ、**全期間のタスクと予定**をファイルの内容に置き換えます |

日単位・週単位の取り込みは「該当日（該当週）の上書き」です。たとえば「すべて」を取り込んで全期間の予定が入っている状態で、ある日の Excel を取り込むと、その日の内容だけが差し替わり、他の日は残ります。

日単位・週単位の取り込みでは、

- 上書き対象の日（週）にあった既存のタスクの配置と予定は、いったん取り消されてからファイルの内容が入ります。
- 同じ名前のタスクが既にある場合は、そのタスクを対象の日へ移動し、所要時間をファイルの値に更新します（同じタスクを複数の日に同時に置くことはできません）。名前が一致しない場合は新しいタスクとして追加します。
- 曜日・開始が空欄の行は、未配置のタスクとして追加されます。
- 時間が重なって置けなかったものは、配置せずにメッセージで知らせます。

そのほか共通の動作：

- 出力したファイルをそのまま取り込めます。Excel や Google スプレッドシートで編集・保存し直したファイル（圧縮形式・共有文字列を使うファイル）にも対応しています。
- 所要時間が読み取れない行や、曜日・開始のない予定の行は読み飛ばし、件数をメッセージで知らせます。

Excel の読み書きは外部ライブラリを使わず、`xlsx.js` で ZIP と OOXML を直接組み立て／解析しています。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | スタイル（ライト／ダークモード対応、レスポンシブ） |
| `app.js` | タスク・予定のCRUD、スケジューリング、週間表へのドラッグ＆ドロップ配置（マウス・タッチ対応）、Excel出力・取り込み、localStorage への保存 |
| `xlsx.js` | 外部ライブラリなしの最小限の `.xlsx` 書き出し・読み込み（ZIP＋OOXML） |
| `i18n.js` | 日本語／英語の文言辞書と、Excelの見出しの別名表 |
