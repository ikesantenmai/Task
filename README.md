# 1日のタスクスケジューラー

タスク名・優先順位・所要時間を入力すると、優先度の高いタスクから **9:00〜18:00** に自動で割り当てるWebアプリケーションです。

## 使い方

ビルドやサーバーは不要です。`index.html` をブラウザで開いてください。

```bash
open index.html        # macOS
xdg-open index.html    # Linux
```

ローカルサーバー経由で開く場合：

```bash
npx http-server -p 8080 .
# → http://localhost:8080
```

## 機能

- **追加**：タスク名／優先順位（1が最優先）／所要時間（分）を入力して登録
- **編集**：一覧の「編集」から内容を修正し「更新する」で反映
- **削除**：タスク単位の削除、および「すべて削除」
- **自動スケジューリング**：優先順位順に 9:00 から連続して割り当て、割り当て時間・空き時間を表形式で表示
- **表からの直接変更**：自動スケジュール表の中で優先順位・所要時間をその場で変更（変更すると即座に再スケジュール）
- **週間スケジュール**：自動スケジュール表の行を下の週間表（月〜日）にドラッグ＆ドロップして、週内の任意の日時に固定
- **予定の入力**：優先度を持たない予定（会議・昼休みなど）を週間表に直接追加・編集・削除
- **タッチ操作対応**：iPhone・iPad などタッチ端末でも指でドラッグして移動（画面端まで運ぶと自動スクロール）
- **優先順位の重複時の比較選択**：既に使われている優先順位を入力すると、対象タスクと既存タスクを並べて「どちらを先に実行するか」を選べます
- **保存**：タスク・予定・配置した時刻はブラウザの localStorage に保存され、再読み込みしても内容が残ります
- **曜日を選んで追加**：自動スケジュール表の各行で曜日を選び、「追加」で週間表のその日へ配置
- **Excel出力**：日単位／週単位を切り替えて `.xlsx` ファイルを出力
- **Excel取り込み**：日単位のファイルは曜日を選んでその日だけに取り込み、週単位のファイルは全体を置き換え

## スケジューリングの仕様

- 対象時間は 9:00〜18:00（540分）。
- 優先順位の数値が小さいタスクから順に、9:00 から間を空けずに割り当てます。
- 優先順位は常に 1〜n の連番になるよう自動で振り直されます（同じ順位のタスクは存在しません）。
- 残り時間に収まらないタスクは飛ばし、後続の短いタスクで空き時間を埋めます。収まらなかったタスクは表の下部に「割り当てできなかったタスク」としてまとめて表示され、そこでも優先順位・所要時間を変更できます。
- 自動スケジュールは1日分の提案です。曜日ごとの実際の予定は、下の週間スケジュールで組み立てます。

## 週間スケジュール（ドラッグ＆ドロップ）

画面下部の週間表は、縦が 9:00〜18:00 の30分刻み、横が今週の月曜〜日曜です（今日の列は色が変わります）。ここには次の2種類を並べられます。

| 種類 | 追加方法 | 見た目 |
| --- | --- | --- |
| 優先度つきタスク | 自動スケジュール表の行の「⠿」をドラッグして落とす | 青いブロック |
| 優先度のない予定 | 週間表の上にあるフォームから追加 | 破線のブロック |

- **移動**：配置したタスクも予定も、ブロック左の「⠿」をドラッグして週内の別の日時へ移動できます。
- **曜日を選んで追加**：ドラッグの代わりに、自動スケジュール表の右端で曜日を選んで「追加」を押すこともできます。自動スケジュールと同じ時刻に置き、そこが埋まっている場合はその日の最も早い空き時間に置きます。
- **タッチ操作**：iPhone・iPad などでも指でドラッグできます（HTML5 のドラッグ＆ドロップではなく Pointer Events で実装しているため）。ドラッグ中に画面の上下端へ運ぶとページが、左右端へ運ぶと週間表が自動でスクロールします。
- タスクのブロックは「解除」で配置を取り消せます（タスク自体は残ります）。すべて取り消す場合は「配置をすべて解除」を使います。
- 予定のブロックは「編集」で名前・日・開始時刻・所要時間を変更でき、「削除」で消せます。
- 同じ日の他のタスク・予定と重なる場合や 18:00 を超える場合は配置されず、表の下にその理由が表示されます。
- 所要時間を変更して配置が成立しなくなったタスクは、自動的に配置が解除されます（メッセージで通知）。予定はそのまま残ります。
- 空いているコマをクリック（タップ）すると、その日時が予定フォームに入ります。
- 配置内容は localStorage に保存され、配置済みのタスクには自動スケジュール表側に「配置済み 8/20（木） 14:00」バッジが付きます。
- 曜日は「今週の月曜からの何日目か」で保存するため、週が変わると同じ曜日の位置に表示されます。

### 予定（優先度なし）の入力

| 項目 | 内容 |
| --- | --- |
| 予定名 | 40文字まで |
| 日 | 月〜日 |
| 開始時刻 | 9:00〜17:30 の30分刻み |
| 所要時間 | 5〜540分 |

タスクは優先順位を持ち自動スケジュールの対象になりますが、予定は優先順位を持たず、週間表に固定される点だけが違います。

## 優先順位の変更と重複時の比較

優先順位は、次の2か所から変更できます。

- 「タスクを追加」フォーム（追加時・編集時）
- 自動スケジュール表の「優先順位」欄（数値を入力して Enter またはフォーカスを外す）

入力した優先順位を既に他のタスクが使っている場合は、比較ダイアログが開きます。

```text
優先順位 2 には既に「定例ミーティング」があります。どちらを先に実行しますか？

  ┌ 「緊急対応」を先にする      所要 30分  → 優先順位 2（先に実行）
  └ 「定例ミーティング」を先にする  所要 1時間 → 優先順位 2（先に実行）
```

選んだほうがその順位になり、もう一方は1つ繰り下がります。以降のタスクの順位も連番のまま自動で詰め直されます。キャンセルすると順位の変更は行われません。

所要時間は自動スケジュール表の「所要時間（分）」欄で直接変更できます（5分単位、5〜540分）。変更するとその場で全体が再スケジュールされます。

## Excel出力・取り込み

画面下部の「Excel出力・取り込み」では、出力される内容がそのままプレビュー表として表示されます。

### 出力

| 範囲 | 内容 | ファイル名 |
| --- | --- | --- |
| 日単位 | 選んだ日に固定したタスク・予定＋未配置のタスク | `schedule-YYYY-MM-DD.xlsx` |
| 週単位 | 月〜日に固定したタスク・予定＋未配置のタスク | `schedule-week-YYYY-MM-DD.xlsx` |

シートの構成は次のとおりです（1行目がタイトル、2行目が範囲（`日単位`／`週単位`）、3行目が見出し、4行目以降がデータ）。

| 種別 | 曜日 | 日付 | 開始 | 終了 | 名称 | 優先順位 | 所要時間（分） |
| --- | --- | --- | --- | --- | --- | --- | --- |
| タスク | 水 | 2026-08-19 | 11:00 | 12:00 | 定例ミーティング | 2 | 60 |
| 予定 | 水 | 2026-08-19 | 12:00 | 13:00 | 昼休み | | 60 |
| タスク | | | | | メール返信 | 3 | 45 |

- **種別**：`タスク`（優先順位あり）か `予定`（優先順位なし）
- **曜日・開始**：週間表に固定している場合のみ入る。空欄なら未配置のタスク
- **終了・日付**：確認用（取り込み時は使いません）

### 取り込み

「Excelを取り込む」から `.xlsx` を選ぶと、`種別` と `名称` の見出し行を探して読み込みます。ファイルが日単位か週単位かで動作が変わります（出力時にシートへ書き込む「範囲」の行で判定し、無い場合はタイトルや曜日の散らばりから推測します）。

| ファイル | 動作 |
| --- | --- |
| **日単位** | 取り込む曜日を選ぶダイアログが開き、**選んだ曜日だけ**をファイルの内容に置き換えます。他の曜日はそのまま残ります |
| **週単位** | 確認のうえ、**タスクと週間表全体**をファイルの内容に置き換えます |

日単位の取り込みでは、

- 選んだ曜日にあった既存のタスクの配置と予定は、いったん取り消されてからファイルの内容が入ります。
- 同じ名前のタスクが既にある場合は、そのタスクを選んだ曜日へ移動し、所要時間をファイルの値に更新します（同じタスクを複数の曜日に同時に置くことはできません）。名前が一致しない場合は新しいタスクとして追加します。
- 曜日・開始が空欄の行は、未配置のタスクとして追加されます。
- 時間が重なって置けなかったものは、配置せずにメッセージで知らせます。

そのほか共通の動作：

- 出力したファイルをそのまま取り込めます。Excel や Google スプレッドシートで編集・保存し直したファイル（圧縮形式・共有文字列を使うファイル）にも対応しています。
- 所要時間が読み取れない行や、曜日・開始のない予定の行は読み飛ばし、件数をメッセージで知らせます。

Excel の読み書きは外部ライブラリを使わず、`xlsx.js` で ZIP と OOXML を直接組み立て／解析しています。

## テキスト出力

画面下部の「テキスト出力」に、そのまま貼り付けられる形式のスケジュールが常に最新の内容で表示されます。**日単位**と**週単位**を切り替えられます。

- **日単位**：選んだ日の自動スケジュール（優先順位順）＋その日に固定したタスク・予定。日はプルダウンで選びます（初期値は今日）。
- **週単位**：月曜から日曜までの、各日に固定したタスク・予定の一覧＋まだ配置していないタスクの一覧。
- **コピー**：クリップボードにコピー（`file://` で開いた場合など、クリップボードAPIが使えない環境では自動的にテキストを選択状態にします）
- **.txt をダウンロード**：日単位は `schedule-YYYY-MM-DD.txt`、週単位は `schedule-week-YYYY-MM-DD.txt`（Windows でも文字化けしないよう BOM 付き UTF-8）

日単位の出力例：

```text
2026/8/20（木） のスケジュール（09:00〜18:00）
============================================

■ 自動スケジュール（優先順位順）
09:00〜11:00  企画書の作成  [優先1・2時間]
11:00〜12:00  定例ミーティング  [優先2・1時間]
12:00〜18:00  （空き時間）  [6時間]

■ 週間スケジュールで固定したタスク・予定
14:00〜16:00  企画書の作成  [優先1・2時間]

--------------------------------------------
タスク 2件 / 割り当て 2件・3時間 / 空き 6時間
```

週単位の出力例：

```text
2026/8/17（月） 〜 2026/8/23（日） の週間スケジュール
============================================

■ 2026/8/17（月）
（予定なし）

■ 2026/8/19（水）
12:00〜13:00  昼休み  [予定・1時間]

■ 2026/8/20（木）
14:00〜16:00  企画書の作成  [優先1・2時間]

■ まだ週間スケジュールに置いていないタスク
- 定例ミーティング  [優先2・1時間]

--------------------------------------------
配置済み 2件 / 未配置のタスク 1件
```

選んだほうがその順位になり、もう一方は1つ繰り下がります。以降のタスクの順位も連番のまま自動で詰め直されます。キャンセルすると順位の変更は行われません。

所要時間は自動スケジュール表の「所要時間（分）」欄で直接変更できます（5分単位、5〜540分）。変更するとその場で全体が再スケジュールされます。

## テキスト出力

画面下部の「テキスト出力」に、そのまま貼り付けられる形式のスケジュールが常に最新の内容で表示されます。

- **コピー**：クリップボードにコピー（`file://` で開いた場合など、クリップボードAPIが使えない環境では自動的にテキストを選択状態にします）
- **.txt をダウンロード**：`schedule-YYYY-MM-DD.txt` として保存（Windows でも文字化けしないよう BOM 付き UTF-8）

出力例：

```text

09:00〜11:00  企画書の作成  [優先1・2時間]
11:00〜12:00  定例ミーティング  [優先2・1時間]

12:45〜17:15  資料レビュー  [優先4・4時間30分]
17:15〜18:00  （空き時間）  [45分]

■ 割り当てできなかったタスク
- 日報作成  [優先5・1時間30分]

--------------------------------------------
タスク 5件 / 割り当て 4件・8時間15分 / 空き 45分 / 未割り当て 1件
```
